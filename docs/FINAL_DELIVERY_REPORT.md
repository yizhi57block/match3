## 二、保留的核心玩法行为

✅ **相邻交换机制** - 仅允许相邻（上下左右）宝石交换
✅ **无效交换回退** - 不产生消除的交换会动画回退，播放 pop 音效
✅ **有效消除检测** - 横向或纵向≥3个相同宝石触发消除
✅ **连锁消除** - 消除后掉落补充可能产生新消除，递归处理
✅ **掉落与补充** - 宝石从上方掉落填补空缺，新宝石从顶部生成
✅ **动画期间输入锁定** - 交换、消除、掉落动画期间 `canPick = false`
✅ **KeyCell 逻辑** - 3个关键道具随机分布（不在底行），到达底部后收集
✅ **胜负判定** - 收集3个关键道具胜利，结算后补充完成且不再触发新消除
✅ **响应式布局** - 宝石尺寸动态计算（48px-100px），棋盘居中，支持宽屏和移动视口

   - 可考虑生成多个尺寸版本（@1x, @2x）

### 7.2 潜在风险

1. **音频格式兼容性**
   - 所有音频为 MP3 格式
   - 现代浏览器基本都支持，但 iOS Safari 早期版本可能有限制
   - 未提供 OGG 等备用格式
   - 风险级别：低（MP3 支持广泛）

2. **WebP 格式兼容性**
   - 大部分图片使用 WebP 格式
   - 旧版浏览器（IE、Safari < 14）不支持
   - 未提供 PNG/JPEG 备用
   - 风险级别：中（现代浏览器都支持，但需考虑目标用户群）

3. **首次加载时间**
   - 总资源 1.2 MB + Phaser 框架 1.4 MB = ~2.6 MB
   - 在慢速网络下可能需要5-10秒
   - 未实现加载进度条
   - 风险级别：低（可接受的单次加载时间）

4. **触摸操作精度**
   - 宝石最小尺寸 48px（配置的 minGemSize）
   - 符合 WCAG 触摸目标建议（≥44px）
   - 但实际手指操作精度需真实设备验证
   - 风险级别：低（已按标准设计）
